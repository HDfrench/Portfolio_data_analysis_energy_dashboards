# README — Tableau Version of the Global Energy Analytics Project

## Overview
This folder contains the **Tableau implementation** of the *Global Energy Analytics* project.

It includes:

- the Tableau workbook (`.twbx`)
- the Tableau-specific data files (`.xlsx`) used by the workbook

Because Tableau requires data to be shaped differently than other environments, the files in this folder are **optimized specifically for Tableau** and may differ from the datasets used in the Python, SQL, or Power BI versions of the project.

---

## Project Purpose
The Tableau dashboard provides an interactive view of:

- electricity generation  
- energy usage  
- population  
- country memberships (ASEAN, EU, G7, G20, OECD)  
- income classifications  

The goal is to explore global energy trends, compare countries and regions, and analyze per-capita metrics.

---

## Notes on the Tableau Version
This is the **finalized Tableau build** of the project.

Other implementations (Python, SQL, Power BI) will be added to the repository once completed.

A separate document in the main repository provides a detailed overview of the architectural considerations and limitations encountered while building this version in Tableau.
